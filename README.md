# Todo List（Orca 外掛）

在 Orca 右側欄管理 todo，到時發送桌面通知，底部狀態列顯示「進行中」與「下一個」todo。

## 功能

- **清單**：上方分頁依狀態過濾「啟用／停用／已完成」（標籤帶筆數），預設「啟用」；切換狀態不會記住，重開面板回到啟用。各狀態外框顏色不同（accent／warning／success）。啟用依「進行中 → 下一次時間」排序。
- **整頁 popup**：點任一項目，整個面板換成內容頁（標題、狀態、時間條件、Markdown 內容），左上角「← 返回」回到清單。內容頁可編輯、測試通知、標記完成、停用／啟用、刪除。
- **欄位**：標題（單行）、要做的事情（多行 Markdown，可切「預覽」）、開始時間、持續時間、重複（每 N 分鐘／小時／天／週／月）、停止條件（不停止／總次數／截止時間）、桌面通知開關、狀態。
- **通知**：每場開始時發送桌面通知。Orca 關著時錯過的場次，下次啟動只補發最新一場，標成「錯過的提醒」。
- **持續時間**：目前只做標記。場次開始後的這段時間算「正在進行」，顯示在側欄最上方的醒目區塊、狀態列，以及內容頁。
- **狀態列**：「進行中：標題（至 HH:mm）」與「下一個：今天 14:00 標題」，沒有時自動隱藏；按下顯示摘要。
- **批次刪除**：勾選要刪的狀態（已完成、停用），列出將刪除的項目，按「確定刪除 N 筆」才執行。啟用中的不會被刪。
- **刪除確認**：單筆刪除與批次刪除都要再按一次確定。

## 行為細節

- 時間格式 `YYYY-MM-DD HH:mm`（也接受 `/` 與 `T`），依本機時區解讀。「帶入現在時間」填入下一個整分鐘。
- 存檔當下以前的場次不會通知：新增或改時間時，不會冒出一串舊提醒。重新啟用時，停用期間錯過的場次也不補發。
- 每月重複遇到小月時落在月底（1/31 → 2/28 → 3/31）。
- 只有「啟用」的 todo 會通知、算正在進行、出現在狀態列。
- 沒填開始時間的 todo 只是清單項目，不通知。

## 與需求的差異

| 需求 | 實作 | 原因 |
|---|---|---|
| 點開來全畫面 popup | 覆蓋整個側欄面板的整頁畫面 | Orca 元件面板沒有 modal／浮層，plugin API 也無法把面板開到主編輯區 |
| 時間欄位 | 文字輸入加格式驗證 | 元件沒有日期選擇器 |
| 有色按鈕 | 成功／警告色以外框 Box 上色 | `Button` 的 tone 只有 accent（solid）與 danger 會上色 |

## 權限

| 能力 | 用途 |
|---|---|
| `storage:own` | 存放 todos（外掛自己的 storage，key `todos`） |
| `notifications:show` | 桌面通知 |

`trusted-worker`：worker 定時（每 15 秒）檢查場次並更新狀態列。manifest 宣告了 `statusBarItems`，Orca 會在外掛啟用期間持續執行 worker。

## 開發

型別檢查工具裝在上一層資料夾（外掛資料夾裡不能有 `node_modules`）。

```sh
cd ..                              # orca-ext/
npm install
npm run check:todo                 # typecheck + validate + test + check
orca plugin dev watch todo-list    # 載入 Orca 開發；第一次會要求 --approve
```

```
src/
├── core/          # panel 與 worker 共用：資料模型、場次計算（schedule）、草稿驗證（draft）、顯示格式（format）
├── worker/        # storage 讀寫（store）、通知與狀態列的計算（engine）
├── worker.ts      # worker 進入點：請求處理、定時檢查
├── panel.tsx      # 右側欄面板
└── protocol.ts    # panel 與 worker 的請求契約
```
